---
name: deploy
description: "Deploy claude-cron tasks. Reads task files and generates the crontab."
---

Deploy claude-cron to this VM. Do the following:

1. **Generate crontab**: read every `.md` file in `~/claude-cron/tasks/`. For each task:
   - Extract the **schedule** (cron expression or natural language like "daily at 9am UTC")
   - Extract **max-turns** (default: 50)
   - Extract **timeout** in seconds (default: 3600)
   - Extract **max-budget** in USD (optional)
   - Extract **model** (optional — full model ID like `claude-haiku-4-5-20251001`, or shorthand like "haiku" which you expand to the latest model ID)
   - Generate a crontab entry:
     `<cron-expr> ~/claude-cron/scripts/run-task.sh <task-name> --max-turns <N> --timeout <S> [--max-budget <USD>] [--model <MODEL>]`

   Also include: `0 4 * * * claude update 2>&1 | logger -t claude-cron-update`

   Add a header comment: `# claude-cron — auto-generated by /deploy (do not edit manually)`

2. **Install the crontab** with `crontab <file>`

3. **Print the installed crontab** for confirmation.

If a task file doesn't specify a schedule, warn and skip it.
If a task uses natural language scheduling (e.g. "every weekday at 9am"), convert to a cron expression.
